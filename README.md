# AdventureWorks Data Analytics Project (SQL + Power BI)

## 📌 Project Overview
This project demonstrates an end-to-end data analytics workflow using the **AdventureWorks** dataset.  
I used **SQL** to clean and transform the raw data, then built an **interactive Power BI dashboard** to visualize key business insights.  

The goal was to analyze sales performance, customer behavior, and budget vs. actual revenue comparisons.

---

## 🛠️ Tools & Technologies
- **SQL Server** – Data cleaning, transformation, and modeling  
- **Power BI** – Data visualization and dashboard creation  
- **Excel/CSV** – Exported data for integration with Power BI  

---

## 📂 Dataset
The project uses Microsoft’s **AdventureWorks Data Warehouse** sample database.  
Key tables used:
- **DimCustomer** → Customer details (name, gender, location)  
- **DimDate** → Calendar data (day, month, year, quarter)  
- **DimProduct** → Product details (category, price, cost)  
- **FactInternetSales** → Sales transactions (who bought, what, when, how much)  
- **SalesBudget** → Planned/budgeted sales for comparison  

---

## 🔑 Key Features
- Data extraction and transformation using SQL  
- Star schema design (Fact + Dimension tables)  
- Built KPIs for **Total Sales, Profit, Orders, and Customer Trends**  
- Visualized **Sales by Product, Customer Demographics, and Geography**  
- Compared **Budget vs. Actual Sales** for business insights

## 🚀 How to Use
1. Restore the **AdventureWorks .bak file** in SQL Server (download from Microsoft’s official site).  
2. Run the SQL script (`portfolio_1-project-analysis.sql`) to clean and prepare data.  
3. Load the exported tables (CSV/Excel) into Power BI.  
4. Open the Power BI file (`portfolio_1-project-visualization_powerbi.pbix`) to explore the dashboard.
